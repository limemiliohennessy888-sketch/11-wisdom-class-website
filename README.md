# 11 Wisdom Class Website

A custom, modern class website for 11 Wisdom. This project is designed as a clean, responsive landing page for a school/class community with a polished and unique look.

## Overview

This website includes:
- A welcoming hero section
- Class highlights and features
- About section
- Responsive layout for desktop and mobile
- Simple custom styling with HTML, CSS, and JavaScript

## Features

- Modern gradient-based design
- Easy-to-edit content sections
- Fully responsive layout
- Lightweight structure
- No Canva export dependency

## File Structure

```bash
11-wisdom-class-website/
├── README.md
├── index.html
└── assets/
```

## Run Locally

1. Open the project folder in your code editor.
2. Launch `index.html` in a browser, or use a local server.

Example using Python:

```bash
cd 11-wisdom-class-website
python3 -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

## Customize

You can easily update:
- The title and tagline
- Feature cards
- About text
- Footer links
- Colors and layout

Edit the content in `index.html` or the connected CSS styles.
